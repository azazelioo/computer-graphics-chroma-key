# ДЗ 4 — удаление и замена фона видео

Веб-приложение для удаления однотонного фона из видео и замены на цвет или изображение. Python, Flask и FFmpeg; запуск в Docker.

## Запуск в Docker

Из каталога проекта:

```sh
docker compose up --build -d
```

Открыть http://127.0.0.1:8004. Остановка:

```sh
docker compose down
```

Docker сам устанавливает FFmpeg и Python-зависимости. Приложение работает от непривилегированного пользователя, с файловой системой только для чтения и отдельным томом `media`. Файлы старше суток удаляются при следующей загрузке. Задания хранятся в памяти: после перезапуска приложения нужно загрузить видео и обработать его заново. Для удаления всех загруженных файлов и результатов: `docker compose down -v`.

## Как пользоваться

1. Нажать **Выбрать видео**. Поддерживаются MP4/MOV/WebM/MKV/AVI/MPEG, если кодеки читает установленный FFmpeg. Лимиты: 256 МБ, 5 минут, до 3840×2160 пикселей.
2. Нажать **Пипетка**, затем на фон в исходном кадре. Можно ввести HEX `#RRGGBB` или выбрать цвет в палитре. Пипетка берёт пиксель из первого декодированного кадра, с учётом масштаба отображения.
3. Настроить **Допуск цвета** и **Мягкость края**. Начинать с небольших значений. Слишком большой допуск удаляет части объекта, слишком большая мягкость делает его полупрозрачным.
4. При зелёном/синем отблеске на объекте включить соответствующий режим **Подавления отблеска**. Для другого цвета хромакея оставить его выключенным.
5. Выбрать новый цвет либо загрузить PNG/JPEG/WebP. Картинка заполняет кадр пропорционально с обрезкой излишков; альфа фоновой картинки не используется.
6. Нажать **Предпросмотр · 5 секунд**. Получится настоящий обработанный MP4 первых пяти секунд, до 960 пикселей по длинной стороне.
7. Нажать **Обработать всё видео**, посмотреть результат и **Скачать MP4**. Полная запись сохраняет исходный размер с округлением нечётных сторон вниз до чётных, длительность и первую аудиодорожку (если есть). Выход: H.264, yuv420p, 30 кадров/с, звук AAC. Это перекодирование с потерями.

Изменение параметров помечает уже показанный результат устаревшим. Повторная обработка обновляет видео. Одновременно выполняется только одно задание; ошибки и ожидание отображаются в интерфейсе. Дедлайн задания — 20 минут. Приложение предназначено для локального запуска; авторизация пользователей не реализована.

## Алгоритм и объяснение для защиты

`server.py` принимает файл, проверяет метаданные через ffprobe и извлекает первый кадр. Браузер получает PNG для точного выбора RGB-цвета. Все параметры проверяются сервером; команды запускаются списком аргументов без shell.

FFmpeg `chromakey` работает в YUV: яркость Y отделена от цветности U,V. Близость цветности пикселя к выбранному ключевому цвету превращается в альфа-маску: совпадающие участки становятся прозрачными, отличающиеся остаются видимыми. `similarity` регулирует область совпадения, `blend` — плавность перехода альфы. Это цветовая сегментация, не нейросетевое распознавание объектов.

Исходник приводится к `yuva444p`, к нему применяется `chromakey`. Опциональный `despill` уменьшает избыточный зелёный/синий компонент, сохраняя альфу. Затем `overlay` совмещает передний план с выбранным фоном: C = alpha × foreground + (1 − alpha) × background. Изображение фона масштабируется с сохранением пропорций и обрезается по центру. Видео кодируется libx264, аудио — AAC. `+faststart` переносит MP4-метаданные в начало для воспроизведения в браузере.

Ограничения метода: объект цвета хромакея тоже исчезает; тени, отражения, волосы, полупрозрачные материалы и смазанные границы требуют настройки и не всегда отделяются идеально. Настройки предпросмотра и полного экспорта используют одну функцию построения фильтров, но масштаб предпросмотра может немного изменить край.

Документация алгоритмов: https://ffmpeg.org/ffmpeg-filters.html#chromakey и https://ffmpeg.org/ffmpeg-filters.html#despill .

## Разработка и проверки

Для запуска без Docker нужны Python 3.11+ и FFmpeg с libx264:

```sh
cd computer-graphics-chroma-key
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

Тесты:

```sh
python -m pip install pytest
python -m pytest tests -q
```

Тесты генерируют видео зелёного/синего экрана с красным объектом и звуком, проверяют пиксели результата, сохранение аудио и длительности, замену на изображение, длительность предпросмотра, ошибки входных данных и скачивание.

## Структура

- `server.py` — API, проверка входных данных, фоновые задания FFmpeg.
- `static/` — веб-интерфейс с пипеткой и видеоплеером.
- `tests/` — проверки обработки и API.
- `smoke.py` — проверка готового Docker-образа.
- `.github/workflows/ci.yml` — тесты и сборка контейнера.

При первой сборке нужен интернет для загрузки Docker-образа, системных пакетов и Python-зависимостей. Для обработки после сборки внешние сервисы не нужны. GitHub Pages не поддерживает сервер Flask и FFmpeg: интерфейс запускается локально через Docker.
