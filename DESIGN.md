# Интерфейс

План: рабочее место монтажа, а не презентационная страница. Слева исходный кадр и обработанный ролик, справа единая панель параметров. На узком экране параметры перемещаются над кадрами. Выравнивание текста влево; содержимое пустого видеокадра по центру.

Палитра: бумага #f0f3f6, текст #192f46, действие #295e91, разделители #ccd6df, поверхность #ffffff, вспомогательный текст #53687b. Типографика Avenir Next / Segoe UI с системным fallback; моноширинный шрифт только для HEX.

Основа композиции — два кадра 16:9. Нет декоративных карточек, анимаций, внешних шрифтов или сетевых ресурсов. Основные действия названы по результату: предпросмотр фрагмента, обработка всей записи, скачивание MP4.
